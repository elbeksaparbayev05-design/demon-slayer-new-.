# Demon Slayer

Anime sahifasi HTML, CSS va JavaScript asosida tuzilgan.

## Ishga tushirish

Loyiha ildizidagi `index.html` faylini brauzerda oching. Sahifalar o'rtasida yuqori menyu orqali o'tish mumkin.

## Papkalar

- `HTML/` — ma'lumot, qahramonlar va anime sahifalari
- `CSS/` — umumiy uslublar
- `JS/` — navigatsiya va epizodlar uchun JavaScript
- `IMAGE/` — sahifa rasmlari va logotip
