# Demon Slayer — muammolar hisoboti

## Tuzatildi

- Bosh sahifa loyiha ildizida joylashgan; root va `HTML/` sahifalaridagi CSS, JavaScript, rasm, favicon hamda navigatsiya yo'llari to'g'rilandi.
- HTML sahifalarining asosiy tili o'zbekcha (`uz`) qilib belgilandi.
- Mobil menyu ochilib-yopiladi, Escape tugmasi va menyu havolalari orqali yopiladi; ARIA holati ham yangilanadi.
- Qahramonlar sahifasidagi “Batafsil” tugmalari tavsifni ochib-yopadi.
- Video iframe uchun sarlavha va kerakli accessibility atributlari qo'shildi.
- Klaviatura orqali fokus ko'rinishi aniqlandi; README ishga tushirish yo'li bilan to'ldirildi.

## Hali kerak bo'lishi mumkin

- Login sahifasi yoki autentifikatsiya funksiyasi loyihada mavjud emas.
- Instagram havolasining haqiqiy manzili berilmagan; Telegram footer havolasi bosh sahifadagi Telegram manzilidan foydalanadi.
